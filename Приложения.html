Установка

Приложение на любом устройстве

На Windows — нативная программа. На Android и iPhone — приложение из сайта через манифест и сервис-воркер. Оба варианта работают офлайн и хранят данные только у вас на устройстве.

Windows

Нативная программа

Полноценное окно на C# и WebView2: своя иконка, рамка в стиле системы, перетаскивание, масштабирование, никакой адресной строки.

Android и iPhone

Установка из браузера

Сайт сделан как Progressive Web App: манифест, иконки, офлайн-кэш. Он ставится на домашний экран как обычное приложение и запускается без браузерной панели.

Android

Chrome

Открой сайт → меню → «Установить приложение» или «На экран „Домой“». Приложение появится на рабочем столе.

iPhone и iPad

Safari

Открой сайт → кнопка «Поделиться» → «На экран „Домой“». Работает в iOS 16.4 и новее.

Настольный браузер

Chrome или Edge

Значок установки появляется в адресной строке. Либо меню → «Приложения» → «Установить».

Сайт должен быть открыт по http, а не двойным кликом по файлу. По протоколу file:// браузеры запрещают регистрацию сервис-воркера, поэтому офлайн-режим не включается. Сама страница при этом работает — не включается именно кэширование.

Локальный сервер — одна команда

python -m http.server 8000
# затем открой http://localhost:8000

Можно и без Python: двойной клик по Запустить_сайт.cmd — он поднимет сервер и откроет браузер.

Локально

Анкета, отметки и выбранные темы лежат в localStorage браузера или в профиле приложения. Никуда не отправляются, с сервера не читаются.

Экспорт

Готовый план выгружается в Word или PDF одной кнопкой. Данные для бота передаются вручную — по коду, который ты сам вставляешь в чат.
